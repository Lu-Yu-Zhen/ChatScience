请对以下数据做训练前质检：

$ARGUMENTS

质检流程：
1. **画像**：用 data_profile 工具统计字段类型、缺失率、数值分布、分类高频值（先读文件片段传入）；
2. **异常**：数值越界/单位混乱/编码问题/重复样本（精确与近似重复分别报告）；
3. **污染**：若同时给出训练与评测集，做重叠检查（键冲突 + 文本 n-gram 重叠抽样）；
4. **划分建议**：给出 train/val/test 比例与分层字段（按标签/来源分层），标注泄漏风险点；
5. **结论**：可用性分级（可直接用 / 清洗后可用 / 不可用）+ 清洗步骤清单。

输出为结构化报告，所有统计数字来自 data_profile 实际输出，不得凭印象估计。
