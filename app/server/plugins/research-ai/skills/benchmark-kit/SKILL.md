# 基准测试协议

设计或审查 AI 基准实验时按此清单执行：

1. **数据**：train/val/test 划分与任务匹配（分布内/分布外分开报告）；检查测试集污染（与训练数据 n-gram 重叠或语义去重）；标注数据来源与许可证。
2. **指标**：主指标与任务目标一致（生成任务不要只报 BLEU，附人工/LLM 评分口径）；多 seed（≥3）报告 mean±std；比较模型时做显著性检验（配对 t 或 bootstrap）。
3. **公平性**：对比实验控制计算预算（FLOPs/训练 token 数）与数据规模；提示词与解码参数（温度/top-p）在所有模型上完全一致并写入附录。
4. **可复现**：脚本 + config 快照 + 环境版本表（框架/CUDA/硬件）；随机种子全部记录。
5. **报告模板**：主表（基线 vs 本文方法）/ 消融表 / 失败案例分析与性能曲线。

输出：完整实验协议文档，缺项逐条标注「缺失」而不是默认通过。
