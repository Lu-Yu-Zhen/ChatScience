# 评测评分细则设计

1. **维度拆解**：从任务目标导出 3~6 个独立维度（如 正确性/完整性/简洁性/安全性），维度间不重叠、可单独判定。
2. **等级锚点**：每维度 3~5 级，每级给「可观察行为」描述（避免「较好」「优秀」等相对词）；附 1~2 个边界示例。
3. **一致性检验**：设计 10+ 条校准样本，两名评分者（或双 LLM）独立打分后算一致性（Cohen's κ ≥0.6 才可用）；分歧样本仲裁并更新锚点。
4. **防作弊**：位置偏置（交换选项顺序复测）、长度偏置（按长度分层看分）、自我偏好（评分模型与被评模型不同源）。
5. **输出**：评分表 schema + 锚点文档 + 校准样本集 + 一致性报告模板。
