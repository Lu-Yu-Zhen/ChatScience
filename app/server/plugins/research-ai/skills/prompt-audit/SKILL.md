# 提示词审查

1. **结构审查**：
   - 角色与目标是否明确；约束是否可执行（可判定的措辞优于模糊形容词）；
   - 输出格式是否给出 schema 或示例；少样本示例与真实输入分布是否一致；
   - 冲突指令检测（同一属性前后矛盾的要求）。
2. **回归用例集**：按类别构造 ≥10 条（常规/边界/对抗/格式敏感），每条标注期望行为；改动提示词后全量回归，输出通过率对比。
3. **消融建议**：逐段移除提示词成分观察影响，区分「关键成分」与「装饰成分」。

输出：问题清单（位置+风险+修法）+ 回归用例集 + 建议的改进版提示词。
