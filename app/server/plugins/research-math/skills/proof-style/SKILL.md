# 数学写作风格

审查或撰写数学文本时执行：

1. **结构惯例**：定理环境用途分明——Theorem（主结果）/ Proposition（次要独立结果）/ Lemma（服务性中间结果）/ Corollary（直接推论）；证明与陈述字号/缩进区分。
2. **符号一致性**：全文一个概念一个符号；集合与元素记号区分（大写 vs 小写）；算子位置统一（pre/infix）；首次出现的符号给出定义。
3. **术语准确**：「当且仅当」vs「若」；「存在唯一」拆成存在性与唯一性分别证明；不等号严格/非严格逐处核对。
4. **可读性**：每个证明先一句话概述策略；关键步骤编号；「显然」只允许用于前一行刚证过的内容。
5. **引用规范**：引用他人结果注明出处编号；自引前文用 Proposition x.y 形式而非「如上所述」。

输出：按问题严重度分组的修改清单（结构/符号/术语/可读性），每条附修改示例。
