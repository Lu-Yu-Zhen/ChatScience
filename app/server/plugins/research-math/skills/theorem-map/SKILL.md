# 定理依赖梳理

输入：一组定理/引理的陈述（文本或文件）。

1. **提取前提**：对每个结果列出用到的定义、已知定理与假设条件。
2. **构建依赖图**：结果 A 用到结果 B 则 A → B；输出拓扑序（证明顺序建议）。
3. **异常识别**：
   - 循环依赖：指出环路并给出打破方案（弱化其中一条的前提或拆分命题）；
   - 孤立结果：与主链无关的结论，建议归并或移入附录；
   - 前提冗余：某定理的假设未被证明实际使用，标注可弱化。
4. **输出**：依赖表 + 拓扑序 + 异常清单；必要时给出 mermaid 图源码。
