请为以下机器人任务生成真机执行前安全检查单：

$ARGUMENTS

检查单要素：
1. 任务描述与运行边界（工作空间包络、速度/加速度上限、人员隔离区）；
2. 力矩裕度：对主要承重关节用 torque_estimate 估算静态重力矩，对照执行器规格给出裕度系数，不足的给出调整建议；
3. 急停链路：硬件急停位置确认、软件看门狗与速度/力矩软件限位、通信中断时的默认行为（零速/保持/阻尼刹车）；
4. 分步执行序列：上电自检 → 通信确认 → 标定 → 空载 → 带载，每步含通过判据与回退动作；
5. 观测指标：运行中需人工盯守的信号（电流/温度/跟踪误差阈值）。

输出为可打勾的 checklist 格式，危险项用【需人工确认】标注。
