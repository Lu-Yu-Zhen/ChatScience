# Sim-toReal 迁移清单

1. **差异来源识别**（按影响排序）：执行器延迟（毫秒级即影响高频控制）、摩擦模型（库伦 vs 黏滞）、间隙与柔性、传感器噪声与丢帧、地面/接触参数。
2. **域随机化范围**：对上表逐项给随机区间（初值 ±20% 起步）；观测噪声与动力学参数分开随机；记录随机化种子以便复现失败回合。
3. **课程式迁移**：仿真成功率 ≥95% → 加噪声 → 换动力学参数 → 真机空载 → 真机带载；每级验收判据量化（成功率/跟踪误差阈值）。
4. **失败分析**：真机失败回合先查「感知对齐（时间戳/坐标系）」再查「动力学差异」；用 torque_estimate 校核电流量级是否与模型一致。
5. **产出**：随机化参数表 + 迁移序列 + 每级回退动作。
