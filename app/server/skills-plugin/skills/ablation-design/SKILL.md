# 消融实验设计

## 设计原则
- 单变量原则：每次只动一个因子；其余超参冻结并写明。
- 对照组：必须含 baseline 与被移除模块的"合理替代"（而不是简单删除）。
- 统计效力：≥3 个 seed；报告均值±标准差；差异小于 1 个标准差时不得声称有效。

## 输出要求
- 实验矩阵表：编号 / 变动因子 / 取值 / seed 数 / 预算（GPU 时）/ 预期回答的问题。
- 每个实验写清"如果结果支持假设，我们会看到什么；如果不支持，说明什么"。
- 结果出来后整理成论文表格格式（方法列 × 指标行），并做显著性判断。

## 配套脚本与资源（位于本技能目录下）
- `scripts/aggregate_results.py` — 结果聚合：多 seed → 均值±标准差 → 与 baseline 按 seed 配对显著性检验（Holm 校正）→ 自动执行"差异 < 1σ 不得声称有效"规则 → 产出论文表格 out/ablation_table.md：`python aggregate_results.py --data runs.csv --baseline base`（CSV 需 config,seed,指标列；`--demo` 看示例）。**结果出来必须跑本脚本**，你负责解读判定与补实验设计。

## 通用约束（每个技能都要遵守）
- 沙箱以本机用户权限运行且无资源硬上限：**先用小样本/小 batch 验证脚本正确，再放大**。
- 需要事实依据时用检索工具（arxiv_search / fetch_url / kb_search）获取，不凭记忆断言；检索结论注明来源。
- 重要结论与实验数据用 note_write 写入笔记本（用户可见），不要只留在对话里。
- 代码放当前目录，图表与结果文件放 out/ 子目录。
- 数学公式用 LaTeX（行内 $...$，独立公式 $$...$$）。
