# 学术写作范式

## 结构范式（IMRaD）
- **引言**：漏斗形——领域重要性 → 现有方法与缺口 → 本文贡献（3 条以内，可验证）。
- **方法**：让同行能复现的精度写；符号表完整；与实验设置（超参/硬件/种子）分节。
- **实验**：每个实验回答一个明确问题；基线与消融分开陈述；负面结果如实报告。
- **讨论/结论**：发现 → 局限 → 未来工作；不引入引言没有的新claim。

## 语言纪律
- 先结论后展开：段首句 = 段落论点；每段只说一件事。
- 时态：方法/结果用过去时，普适结论用现在时；避免「很明显」「众所周知」。
- 术语一致：同一概念全文一个词；缩写首次出现给全称。
- 改写用户口语稿时保留原意，标注不确定的改写（存疑处列表请用户确认）。

## 引用与图表
- 引用用 doi_cite 工具生成（BibTeX + GB/T 7714）；关键 claim 必须有引用或本工作数据支撑。
- 图表注用 figure_caption 工具按规范生成；正文先引用后出现（"如图 X 所示"）。
- 数字三处一致：摘要 = 正文 = 表格。

## 输出要求
- Markdown 落盘（Write 到当前目录）；公式用 LaTeX；公式交付前跑 latex_check 自检。
- 交稿附一段「自查清单」：结构完整 / 术语一致 / 引用对应 / 数字一致。

## 通用约束（每个技能都要遵守）
- 沙箱以本机用户权限运行且无资源硬上限：**先用小样本/小 batch 验证脚本正确，再放大**。
- 需要事实依据时用检索工具（arxiv_search / fetch_url / kb_search）获取，不凭记忆断言；检索结论注明来源。
- 重要结论与实验数据用 note_write 写入笔记本（用户可见），不要只留在对话里。
- 代码放当前目录，图表与结果文件放 out/ 子目录。
- 数学公式用 LaTeX（行内 $...$，独立公式 $$...$$）。
