# 因果变量梳理

## 流程
1. 列出研究问题中的候选变量池：处理/暴露、结局、机制变量、背景变量。
2. 逐对判定关系类型：因果 / 相关 / 反向因果 / 共因（混杂）/ 中介 / 调节 / 碰撞。
3. 画因果图（DAG，文字或 Mermaid）：箭头只画有依据的，依据写明（领域常识/文献/数据）。
4. 识别策略：随机分组 / 匹配 / 回归控制 / 工具变量 / 断点——给出本场景可行的最优项。
5. 声明局限：哪些混杂无法排除、哪些结论只在小样本/特定分布下成立。

## 输出要求
- 变量表：变量 / 角色 / 度量方式 / 取值范围 / 是否可控。
- 明确写出「调节变量」与「中介变量」的检验方法差异（交互项 vs 分解）。
- 相关 ≠ 因果：凡从相关数据得出的结论，必须附一句边界声明。
- 结论写 note_write，供实验设计与评审环节引用。

## 通用约束（每个技能都要遵守）
- 沙箱以本机用户权限运行且无资源硬上限：**先用小样本/小 batch 验证脚本正确，再放大**。
- 需要事实依据时用检索工具（arxiv_search / fetch_url / kb_search）获取，不凭记忆断言；检索结论注明来源。
- 重要结论与实验数据用 note_write 写入笔记本（用户可见），不要只留在对话里。
- 代码放当前目录，图表与结果文件放 out/ 子目录。
- 数学公式用 LaTeX（行内 $...$，独立公式 $$...$$）。
