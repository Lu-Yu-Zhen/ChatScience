# 数据分析

## 流程
1. 先看数据：shape、dtype、缺失、分布（describe + 直方图），把发现写出来再动手。
2. 清洗规则写明（去重、缺失策略、异常值判定标准），可追溯。
3. 统计方法与假设匹配：正态性、方差齐性先查；小样本用非参数检验。
4. 结论附效应量与置信区间，不只给 p 值。

## 输出要求
- 用 run_code + pandas/numpy 完成；中间表保存到 out/。
- 每个结论一行"证据：来自哪个表的哪个数字"。
- 避免多重比较谬误：多组比较时说明是否校正。

## 配套脚本与资源（位于本技能目录下）
- `scripts/stat_tests.py` — 统计检验流水线（numpy+scipy）：描述统计 → 正态性/方差齐性 → 自动选检验 → 效应量 + 95% CI → Holm 多重比较校正，输出标准报告：`python stat_tests.py --data results.csv --value acc --group method`（长格式 CSV；`--demo` 看示例）。**检验类结论必须出自该脚本**，脚本管方法选择与校正，你负责核对数据是否满足方法前提。

## 通用约束（每个技能都要遵守）
- 沙箱以本机用户权限运行且无资源硬上限：**先用小样本/小 batch 验证脚本正确，再放大**。
- 需要事实依据时用检索工具（arxiv_search / fetch_url / kb_search）获取，不凭记忆断言；检索结论注明来源。
- 重要结论与实验数据用 note_write 写入笔记本（用户可见），不要只留在对话里。
- 代码放当前目录，图表与结果文件放 out/ 子目录。
- 数学公式用 LaTeX（行内 $...$，独立公式 $$...$$）。
