# 实验记录

## 记录模板（note_write 写入笔记本）
```markdown
# [日期] 实验名称
## 目的：验证什么假设
## 配置：模型/数据/超参/硬件（完整到可复现）
## 环境：mindspore 版本、CUDA、包版本（pip freeze 摘要）
## 结果：核心指标表 + 曲线文件路径（out/…）
## 观察与解释：与预期一致/不一致的点
## 结论与下一步
```

## 纪律
- 每次实验结束（或每个阶段）主动写一条笔记；不要等用户要求。
- 失败实验同样记录：负结果与失败原因是重要信息。
- 关键数字（指标、耗时、显存）必须原样记录，不做舍入美化。

## 配套脚本与资源（位于本技能目录下）
- `scripts/env_capture.py` — 「环境」小节一键生成（时间/Python/关键包/GPU/备注）：`python env_capture.py --extra "A100 80G x4"`，输出直接粘进 note_write。比 mindspore-repro 的 env_probe 精简，非复现场景用它。

## 通用约束（每个技能都要遵守）
- 沙箱以本机用户权限运行且无资源硬上限：**先用小样本/小 batch 验证脚本正确，再放大**。
- 需要事实依据时用检索工具（arxiv_search / fetch_url / kb_search）获取，不凭记忆断言；检索结论注明来源。
- 重要结论与实验数据用 note_write 写入笔记本（用户可见），不要只留在对话里。
- 代码放当前目录，图表与结果文件放 out/ 子目录。
- 数学公式用 LaTeX（行内 $...$，独立公式 $$...$$）。
