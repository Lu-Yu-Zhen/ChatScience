# 公式推导

## 推导纪律
- 每步只做一个变换，并注明依据（代数恒等式、链式法则、分布函数定义等）。
- 先声明符号表：所有变量的含义、维度、取值范围。
- 终点回代验证：特例（如 d=1、n→∞、线性情形）代入检查。
- 量纲/维度一致性检查：矩阵乘法维度逐项核对。

## 输出要求
- 用 LaTeX 独立公式逐行呈现，重要步骤右侧标注理由。
- 结论与中间结果分开陈述；数值近似需给出误差来源。
- 用户给出推导让你检查时：先复述其思路，再逐步核对，错误处给出反例或正确推导。

## 配套脚本与资源（位于本技能目录下）
- `scripts/grad_check.py` — 推导结果的机械验证（numpy + sympy）。**终点回代验证不要心算**：在 run_code 里 `sys.path.insert(0, r"<技能目录>/scripts")` 后 `import grad_check`，用 `grad_check.verify_gradient(f, grad, x)` 对拍数值梯度、`verify_expression(expr, deriv, var)` 符号核验、`dim_audit([...])` 维度审计。直接运行 `python grad_check.py` 看示例与输出格式。

## 通用约束（每个技能都要遵守）
- 沙箱以本机用户权限运行且无资源硬上限：**先用小样本/小 batch 验证脚本正确，再放大**。
- 需要事实依据时用检索工具（arxiv_search / fetch_url / kb_search）获取，不凭记忆断言；检索结论注明来源。
- 重要结论与实验数据用 note_write 写入笔记本（用户可见），不要只留在对话里。
- 代码放当前目录，图表与结果文件放 out/ 子目录。
- 数学公式用 LaTeX（行内 $...$，独立公式 $$...$$）。
