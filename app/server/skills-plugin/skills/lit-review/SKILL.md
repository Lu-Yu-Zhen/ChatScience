# 文献综述

## 流程
1. 澄清研究问题与检索范围（时间窗、venue、关键词组合）。
2. 用 arxiv_search 多轮检索（同义词、缩写全称都试），去重后建立候选清单。
3. 对入选论文抓摘要（fetch_url 或 arxiv summary），按方法/数据/结论聚类。
4. 产出对比表：方法 / 核心思想 / 数据集 / 指标 / 局限。
5. 找空白：哪些组合没人做、哪些结论相互矛盾。

## 输出要求
- 每条引用给 arXiv id 与链接；检索式写明（可复现）。
- 区分"论文声称"与"你核实过的"；未核实的标注。
- 综述正文按主题组织，不按时间流水账。

## 配套脚本与资源（位于本技能目录下）
- `references/query_patterns.md` — 检索式模板（按目的选式 + 多变体纪律），多轮检索前先读。
- `scripts/bib_export.py` — 入选清单 → BibTeX（按 arXiv id 去重、自动生成 citation key）：`python bib_export.py --input papers.json` 或 `--ids "2401.12345,..." --fetch`（走 arXiv 官方 API，需网络）。引用清单交付时用。

## 通用约束（每个技能都要遵守）
- 沙箱以本机用户权限运行且无资源硬上限：**先用小样本/小 batch 验证脚本正确，再放大**。
- 需要事实依据时用检索工具（arxiv_search / fetch_url / kb_search）获取，不凭记忆断言；检索结论注明来源。
- 重要结论与实验数据用 note_write 写入笔记本（用户可见），不要只留在对话里。
- 代码放当前目录，图表与结果文件放 out/ 子目录。
- 数学公式用 LaTeX（行内 $...$，独立公式 $$...$$）。
