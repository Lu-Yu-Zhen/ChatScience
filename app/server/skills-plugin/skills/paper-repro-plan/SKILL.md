# 复现实施计划

## 工作流程
1. **可复现性审计**：逐项检查论文是否给出：完整超参、数据预处理、训练时长与硬件、随机种子、代码链接。
2. **缺口清单**：对缺失信息给出标注等级——[给定] / [可推断] / [需假设]，并写出你采用的假设值。
3. **分阶段计划**：
   - 阶段 0：环境与数据管道打通（最小 batch 跑通前向）
   - 阶段 1：小规模训练收敛验证（对比论文小数据集/短训练曲线）
   - 阶段 2：全量复现与指标对齐（明确容差，如 ±2%）
4. **验收标准**：每阶段给出可量化的通过条件与预期产物（表/曲线/日志）。

## 输出要求
- 计划用表格：阶段 / 目标 / 具体步骤 / 验收标准 / 预计产物。
- 明确指出哪些环节最可能复现失败及原因（数值稳定性、未公开超参、硬件差异）。

## 配套脚本与资源（位于本技能目录下）
- `references/plan_and_checklist.md` — 可复现性审计清单（8 项三态判级）+ 分阶段计划模板（量化验收）+ 高风险预告表，产出计划时直接套用该结构。

## 通用约束（每个技能都要遵守）
- 沙箱以本机用户权限运行且无资源硬上限：**先用小样本/小 batch 验证脚本正确，再放大**。
- 需要事实依据时用检索工具（arxiv_search / fetch_url / kb_search）获取，不凭记忆断言；检索结论注明来源。
- 重要结论与实验数据用 note_write 写入笔记本（用户可见），不要只留在对话里。
- 代码放当前目录，图表与结果文件放 out/ 子目录。
- 数学公式用 LaTeX（行内 $...$，独立公式 $$...$$）。
