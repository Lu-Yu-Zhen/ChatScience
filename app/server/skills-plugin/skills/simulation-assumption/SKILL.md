# 仿真假设校验

## 事前清单（跑之前逐项过）
1. **量纲一致性**：所有公式两侧量纲核对（可用 unit_convert 工具换算统一单位）。
2. **边界条件**：初值/边界是否物理合理（能量有界、概率归一、浓度非负…）。
3. **收敛判据**：预先写下「怎样算收敛」——残差阈值、迭代上限、指标平台判定，不做事后解释。
4. **数值稳定性**：步长/学习率与特征尺度匹配（CFL 条件、梯度尺度、fp16 溢出风险）。
5. **基准锚点**：至少一个可解析解/已知结果做对照（缩小规模到能手算的特例）。

## 事后核对
- 结果与假设相容吗？出现「好得不像话」的结果先查泄漏（测试集混入、边界吸收了不该吸收的量）。
- 发散/震荡按症状定位：NaN（先查 log(0)/除零/fp16 溢出）→ 尖峰（数据异常）→ 平台（容量/lr）。
- 把「假设 → 预期 → 实测 → 偏差解释」写成四列表格，note_write 落盘。

## 输出要求
- 任何仿真结论必须能追溯到：假设清单 + 收敛判据 + 基准对照三项，缺一视为未完成。
- 需要联网/集群跑的任务如实说明当前沙箱的限制，不假装已运行。

## 通用约束（每个技能都要遵守）
- 沙箱以本机用户权限运行且无资源硬上限：**先用小样本/小 batch 验证脚本正确，再放大**。
- 需要事实依据时用检索工具（arxiv_search / fetch_url / kb_search）获取，不凭记忆断言；检索结论注明来源。
- 重要结论与实验数据用 note_write 写入笔记本（用户可见），不要只留在对话里。
- 代码放当前目录，图表与结果文件放 out/ 子目录。
- 数学公式用 LaTeX（行内 $...$，独立公式 $$...$$）。
