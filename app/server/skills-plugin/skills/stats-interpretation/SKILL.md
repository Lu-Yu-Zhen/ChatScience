# 统计审慎解读

## 解读纪律
1. **先报效应量与置信区间，再报 p 值**：p<0.05 而效应量微小的结果不得表述为「显著提升」。
2. **前提核对**：正态性（Shapiro/Wilks 或 QQ 图）、方差齐性、独立性——小样本（n<30）默认用非参数检验。
3. **多重比较**：≥3 组比较必须说明校正方式（Bonferroni / Holm / FDR），未校正要明说。
4. **样本量诚实**：n 是多少就是多少；删失/剔除的样本数与理由写明。
5. **相关 ≠ 因果**：凡观察性数据，结论限用「相关/关联/预测」，禁止「导致/提升/降低」这类因果动词。

## 常见误读速查
- p 值不是「假设为真的概率」；不显著 ≠ 无差异（可能是功效不足）。
- R² 高不等于预测好（过拟合）；交叉验证结果才可外推。
- 事后子组分析（subgroup）是探索性的，表述必须降级。

## 输出要求
- 每个统计结论一行三要素：检验方法（含前提核对结果）/ 效应量 [95% CI] / p 值（校正后）。
- 结论分级：[确证] 预注册或强设计支撑 / [一致] 多来源证据汇聚 / [探索] 单次观察。
- 数值表用 note_write 落盘，图表按 figure-plot 规范出图。

## 通用约束（每个技能都要遵守）
- 沙箱以本机用户权限运行且无资源硬上限：**先用小样本/小 batch 验证脚本正确，再放大**。
- 需要事实依据时用检索工具（arxiv_search / fetch_url / kb_search）获取，不凭记忆断言；检索结论注明来源。
- 重要结论与实验数据用 note_write 写入笔记本（用户可见），不要只留在对话里。
- 代码放当前目录，图表与结果文件放 out/ 子目录。
- 数学公式用 LaTeX（行内 $...$，独立公式 $$...$$）。
