# 论文自查

## 检查清单
1. **结构**：摘要-引言-方法-实验-结论要素齐全；章节编号连续；图表先引用后出现。
2. **引用**：正文引用与文献表一一对应（数量、年份、作者拼写）；关键声明有出处；无自引堆砌。
3. **术语**：同一概念全文用词一致（如 attention/自注意力 不混用）；缩写首次定义。
4. **数字**：摘要与正文与表格中的同一指标数值一致；百分比基数写明。
5. **公式与符号**：符号表完整；公式编号被引用；上下标清晰。

## 输出要求
- 问题清单表格：位置（章节/页）/ 问题类型 / 原文摘录 / 修改建议 / 严重度（高中低）。
- 用户提供文档时用 kb_search 定位原文，引用处给位置，不要凭印象。

## 配套脚本与资源（位于本技能目录下）
- `scripts/audit.py` — 机械检查四件套（引用↔bib 交叉、图表编号连续性与先引用后出现、缩写未展开、术语混用）：`python audit.py --file thesis.tex --bib refs.bib --terms terms.csv`。**先跑脚本**，你复核其报告并补语义类问题（论证、数据一致性）；报告是启发式，每条给行号可定位原文。`--demo` 看示例。

## 通用约束（每个技能都要遵守）
- 沙箱以本机用户权限运行且无资源硬上限：**先用小样本/小 batch 验证脚本正确，再放大**。
- 需要事实依据时用检索工具（arxiv_search / fetch_url / kb_search）获取，不凭记忆断言；检索结论注明来源。
- 重要结论与实验数据用 note_write 写入笔记本（用户可见），不要只留在对话里。
- 代码放当前目录，图表与结果文件放 out/ 子目录。
- 数学公式用 LaTeX（行内 $...$，独立公式 $$...$$）。
