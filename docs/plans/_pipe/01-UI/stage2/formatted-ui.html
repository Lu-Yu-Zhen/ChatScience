二、设计语言总纲

2.1 定位

【已实现】 代码注释明确记载了本产品的视觉定位："去 AI 味：中性色 + 墨色主按钮 + 克制蓝链接"（01/主页面.html:19）。

这一定位与品牌名的"墨"字高度自洽，且已在全套令牌中系统落实，应作为长期设计纲领保留：

  1. 中性色打底 — 界面大面积使用不带色相倾向的中性灰白（--bg: #F6F7F9），不使用任何彩色背景铺底，避免长时间科研工作下的视觉疲劳与"AI 产品感"。
  2. 墨色主按钮 — 主按钮不用品牌色，而用近黑的墨色（--primary-bg: #0F172A），形成"墨"的视觉锚点与高级克制的质感。
  3. 克制蓝链接 — 链接是界面上唯一的常规彩色元素，使用克制的蓝（--link: #2563EB），仅用于可点击文本，不做装饰。
  4. 零 emoji — 主页面文件内 emoji 数量为 0，状态与操作全部由内联 SVG 表达。

2.2 设计原则（供后续扩展遵循）

原则含义落地约束
内容优先界面不抢内容无彩色背景铺底；装饰仅限细线与留白
克制的色彩彩色是稀缺资源全局彩色仅用于：链接、状态（成功/警告/危险）、图表。其余一律中性色
一致性优先于表现力专业用户依赖肌肉记忆主题切换为"换肤"不改版：布局、间距、组件位置、图标形态零变化
静默的动效动效服务于状态理解150—300ms；绝不因内容更新触发容器动画
可访问性为硬约束不是可选项正文对比度 ≥ 4.5:1；状态不得仅靠颜色区分；键盘可达

3.2 令牌的语义分组（用于主题扩展）

【已实现】 现令牌天然分为五组，这是六套主题扩展的映射骨架：

  1. 基础层（--bg / --panel-bg / --surface / --surface-2 / --content-bg / --main-bg）——背景与面板
  2. 边界层（--border / --border-soft / --panel-border / --menu-border）——分割与描边
  3. 文字层（--text-1 / --text-2 / --text-3）——三级文字
  4. 品牌与交互层（--primary-* / --link* / --accent-* / --hover-overlay / --conv-active-bg / --chip-bg）——主色、链接、强调、交互反馈
  5. 语义状态层（--ok* / --warn* / --danger*）——成功/警告/危险

扩展规则：新增主题只需为这五组各提供一套值，任何主题不得改变组内的语义关系（如 --text-1 必须比 --text-2 对比度更高）。

8.3 下拉菜单【已实现 — 含重要架构决策】

核心问题与解法：.dropdown-menu 类默认 opacity: 0; pointer-events: none（配合父级 .open 解除）。这导致两类故障：

  1. 智能体/权限/模型菜单由 JS 直接切 display、父级不挂 .open → 菜单"打开"后透明且不可点（表现为"点击无响应"）。修复：按 ID 特异性覆盖 opacity: 1; transform: none; pointer-events: auto。
  2. .input-box 的 overflow-y: auto 裁剪向上弹出的绝对定位菜单（实测 elementFromPoint 命中 textarea）。修复：实现 openDropdownMenu / closeDropdownMenu 门户（Portal）——打开时把菜单挂到 body 下用 position: fixed 动态定位（left/width/bottom 由 getBoundingClientRect 计算），关闭时归位。

规范（后续所有下拉必须遵守）：

  • 一律使用门户方案，不在有 overflow 的容器内做绝对定位弹层
  • 默认隐藏态用 opacity + pointer-events，不用 display: none（保证过渡动画）
  • z-index: 300（浮层）/ 9000（标题栏）
  • 箭头 .chev 旋转 0.22s cubic-bezier(0.22,1,0.36,1)

B4PDF 重渲染重影未清空旧 canvas/textLayer/标注层重渲染前显式清空三层 DOM，再重建
B5侧栏动画误触发切会话时侧栏出现无意义动画确认 transition 仅挂在 .anim 类下；会话列表用签名守卫跳过重建

15.4 C 组：主题系统扩展（P1）

前置：A 组必须完成，否则新增主题无法覆盖硬编码颜色，会出现"换主题后局部颜色不变"。

修改方向：

  1. 新增扩展令牌（4.2.1 节清单）——--font-ui / --font-serif / --radius-card / --radius-btn / --radius-tag / --density / --texture-opacity / --panel-alpha / --panel-blur / --chart-1..6。这些是六套主题的必要条件，缺一不可。
  2. 落地 12 份令牌赋值——六套主题（mono / ink-green / sky-sea / cinnabar / nostalgia / glass）各配明暗两版，按 4.2.2 节给出的完整映射表逐条写入。
  3. 材质层——data-material="glass" 控制半透明与背景模糊、data-texture="paper" 控制底纹；磨砂玻璃主题的可读性红线必须遵守：正文与节点文字用实色，代码区与图表区背景不半透明。
  4. 对比度自动校验——保存自定义主题前，自动计算 --text-1 对 --bg、--text-2 对 --surface 的对比度，低于 4.5:1 拒绝保存并提示具体令牌。
  5. 主题无关性回归——按第十二章的验收方式，同一页面在六套主题下截图逐项比对几何量，必须像素级一致，仅颜色与材质不同。
