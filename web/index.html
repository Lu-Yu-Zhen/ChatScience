ChatScience 桌面版

把模型、技能、工具与沙箱装进一个 Windows 客户端：Chat 模式做对话与知识管理，Work 模式跑科研工作流——数据分析、文献检索、实验记录、子智能体委派，全程可追溯。

便携版 · 解压即用 · 无需安装 · Windows 10/11 64 位 · v1.0.0

其中有何

Features

一个 Electron 客户端，加一个只绑在本机 127.0.0.1 的后端服务，不对外暴露端口。

壹

Chat 模式

多会话对话、项目工作区、模型与供应商管理（BYOK 自带密钥）、右侧栏阅读模式与文献库。

貳

Work 模式

科研工作台：智能体与技能、MCP 工具、沙箱执行、实验笔记、运行轨迹，一条链路跑完。

叁

三个内置插件

research-ai、research-math、research-robotics，各带智能体、技能、命令与工具，可按需启用。

肆

十二套主题

十二套扩展主题加浅色深色，其中八套带壁纸；主题色只上外壳，不动布局与间距。

如何使用

Getting started

便携版，整个文件夹可随意拷贝到其他 Windows 机器。

一

下载并解压——从 Releases 拿到压缩包，解压到任意目录，路径含中文也没问题。

二

双击 ChatScience.exe——首次启动如被杀毒软件拦截，选择允许即可；后端会自动选一个空闲端口，默认 8642。

三

填一个 API Key 就能聊——未配置模型时会自动建一条百炼 qwen3.8-flash 默认条目，填入 Key 即可；也可以自己加供应商与模型。

注意 用户数据写在解压目录的 resources\app\data\ 下，删掉该文件夹即重置应用。若要把这个文件夹分享给别人，请先清理其中的 qoder.json 与 config.json——这两个文件分别存有访问令牌与 API Key。

系统要求

Requirements

桌面端只支持 Windows；仓库里其余脚本跨平台可跑。

项目要求
操作系统Windows 10 / 11，64 位
磁盘空间约 400MB（解压后含 Electron 运行时）
内存建议 8GB 及以上
网络运行期需访问模型服务；首次下载需访问 GitHub
额外依赖无。便携版自带 Node 运行时，不要求系统安装 Node

还没有 release，或想要最新版

From source

源码仓库为私有，需要有访问权限的 GitHub 账号才能克隆。

一

克隆仓库——git clone https://github.com/Lu-Yu-Zhen/ChatScience.git

二

装依赖并构建渲染层——cd app && npm install && node build.js（app/renderer/ 不入库，必须先构建）

三

启动或打包——开发用 npm start 或双击 start.bat；打包用 node pack.js，产物在 app/dist/

常见问答

FAQ

更多细节见源码仓库里的 README 与知识库。

启动后白屏或提示找不到页面？

说明渲染层还没构建。解压版不会出现这个问题；如果是自己克隆的仓库，先在 app/ 目录跑一次 node build.js。

端口被占用怎么办？

后端默认监听 8642，被占用时会自动依次尝试 17462、27511、38123、2917、3218，实际端口记录在 app/data/runtime.json，一般无需干预。

杀毒软件报毒？

便携版未做代码签名，部分杀毒软件会对未签名的 Electron 可执行文件发出提示。请只从本页或仓库 Releases 获取安装包，并自行判断是否信任。

密钥存在哪里？会上传吗？

API Key 与访问令牌只写在本机 app/server/config.json 与 app/server/qoder.json，随请求发往你配置的模型服务提供商；项目方不收集、不经手。

能换模型吗？

能。界面里可自行添加供应商与模型（BYOK），后端 ai.ts 走兼容 OpenAI Chat Completions 协议的上游。
