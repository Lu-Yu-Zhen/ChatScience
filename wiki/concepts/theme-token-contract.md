# 主题令牌契约

> 一句话摘要：主题令牌契约规定每套主题必须命名化覆盖哪几组令牌、必须守住哪条对比度与色相距离门槛、新增一套主题要同时落在哪几个注册点，以及配色如何随壁纸取值。

## 命名与分组

令牌一律是 CSS 自定义属性，经 `html[data-theme]` 成组覆盖，基础两套定义在 `:root`（`01/主页面.html:20-92`，68 个属性）与 `html[data-theme="dark"]`（`01/主页面.html:93-160`）。每套扩展主题都写满同一批令牌——只此青绿一块即 66 行赋值（`01/主页面.html:169-236`）；少数令牌刻意只在个别主题出现，未定义时回落 `:root`，`--btn-primary-text` 就走这条路（`01/主页面.html:1107-1109`）。

语义分组是契约的骨架（`01/主页面.html:162-166`）：基础层（`--bg / --panel-bg / --canvas-bg / --surface / --surface-2 / --content-bg`）、边界层（`--border / --border-soft / --panel-border / --menu-border`）、文字层（`--text-1/2/3`）、品牌与交互层（`--primary-* / --link* / --accent-* / --hover-overlay / --conv-active-bg / --chip-bg`）、语义状态层（`--ok* / --warn* / --danger*`），再加材质与内容层（`--hl-* / --paper* / --chart-1..6`，`01/主页面.html:78-91`）。

## 可核验门槛

1. **语义不变式**：`--text-1` 对比度 > `--text-2` > `--text-3`，正文对背景 ≥ 4.5:1，阴影随主题色相走暗色基——三条写死在扩展主题总注释里（`01/主页面.html:165-166`）。
2. **主色白字区间**：主色承载白字的对比度须落回"主题家族区间 6.1–18:1"，例：桃林主色由绛桃木加深为 `#94405A` 才拿到 6.5:1（`01/主页面.html:797`）；燕云十六声调完后 8.59:1（`01/主页面.html:876`）；风花雪月 9.4:1（`01/主页面.html:724`）；办公日常 5.06:1 并配套链接 9.68:1（`01/主页面.html:1030-1031`）。
3. **侧通道兜底**：`.btn-primary` 的文字色走 `--btn-primary-text`，兜底 `#FFFFFF`；经典QQ 的 `#12B7F5` 对白字只有 2.3:1，故该套把文字改深墨 `#08131F` 拿到 8.12:1，其余 11 套不定义该令牌、行为不变（`01/主页面.html:1107-1109`、消费点 `:1507-1509`、赋值点 `:1350`）。
4. **主题间的色相距离**：相邻同调主题必须拉开 ΔE≥12——燕云十六声的青由 H180 折中到 H191，既贴壁纸的 H196-208 又与水墨江南（黛瓦墨 H204）保持 ΔE≥12（`01/主页面.html:872-877`）。
5. **同族层次量化**：同套内轨道/外壳/选中行/描边的对比比例被写成实测数值（桃林：轨道 vs 外壳 1.16、选中行 1.26、描边 1.35，`01/主页面.html:799`）。

## 着色范围（硬约束）

主题色只允许上外壳——侧边栏、标题栏左段、顶部栏与浮层；聊天画布 `.chat-body` 与右栏 `#rightPanel` 由一条十二主题共用规则把整套令牌钉回亮色基（选择器 `01/主页面.html:1181-1208`，钉回值 `:1209-1267`）。`--btn-primary-bg / --btn-primary-hover / --switch-on` 与 `--input-edge / --input-soft` **不进钉回块**，因此暗色主题下的聊天画布仍然跟主题走（`01/主页面.html:1333-1350`、`:1513-1518`）。壁纸层同理只改 `background` 层，不动任何布局/圆角/间距（`01/主页面.html:255`）。

## 注册点（缺一套就不生效）

1. CSS 令牌块 `html[data-theme="<id>"] { … }`（`01/主页面.html:169` 起，共 12 套扩展 + light/dark）。
2. 按钮/开关侧通道那一行的同 id 覆盖（`01/主页面.html:1337-1350`）。
3. `SETTINGS_PREF_PANELS.theme` 里的卡片描述符 `{id, name, bar, bg}`（`app/src/webapp/webapp.ts:1428-1449`）；注释明写"id 不变 = CSS 选择器/持久化不动"（`app/src/webapp/webapp.ts:1424-1426`）。
4. i18n 词条 `optXxx` 中英各一份（`app/src/webapp/webapp.ts:161-163`、`:345-347`）。
5. 有壁纸的八套另需 `html[data-theme="<id>"] body.is-initial-chat #centerPanel` 规则（`01/主页面.html:256-321`），素材来自 `主题壁纸/`。
6. 验证脚本的主题枚举（`app/verify/input-edge-check.js:38-45`）。

**id 与显示名解耦**是既有事实：`cinnabar` 现名「水墨江南」、`glass` 现名「万山红遍」（`app/src/webapp/webapp.ts:1433`、`:1437`），改色改名的正确做法是保留 id、只动第 3/4 个注册点。

## 随壁纸调色

八套主题的整体取向按对应壁纸主色调重写，并给出色相占比与实测采样：风花雪月按"98% 青蓝、平均 S=0.259 V=0.674"废弃原「青莲黛紫」改走月夜蓝灰（`01/主页面.html:720-725`）；办公日常按暖白占六成、办公蓝 7.9% 把主色由暖石墨换成办公蓝（`01/主页面.html:1027-1031`）；燕云十六声按"95% 青蓝（180-239°）"把 H180 微调至 H191（`01/主页面.html:872-877`）。内联口径统一为长边 1600 / JPEG q82 / progressive（`01/主页面.html:248`），白蛇缘起 / 经典QQ / 桃林 / 现代简约四套暂无壁纸（`01/主页面.html:240`）。
