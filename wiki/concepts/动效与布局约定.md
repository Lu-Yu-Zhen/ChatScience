# 动效与布局约定

墨台 UI 的长期硬约束：动效服务于状态理解而非装饰，布局几何量跨主题恒定，视觉基调"去 AI 味"。

## 去 AI 味设计原则（是什么/为什么）

完整纲领见 [去AI味设计](去AI味设计.md)，此处仅列与动效/布局直接相关的四条落地。代码注释原文："**去 AI 味：中性色 + 墨色主按钮 + 克制蓝链接**"（`01/主页面.html:19`）：

1. 中性色打底，无彩色背景铺底（避免科研长时使用的视觉疲劳与"AI 产品感"）；
2. 主按钮用近黑墨色 `--primary-bg` 而非品牌色（"墨"的视觉锚点）；
3. 链接是界面唯一常规彩色元素，仅用于可点击文本；
4. **零 emoji**，状态与操作全部内联 SVG（24 网格、stroke 2、`SVG_ICON_RE` 白名单防注入）。

配套原则：内容优先、彩色是稀缺资源、一致性优先于表现力（主题=换肤不改版，见 [主题系统](../entities/主题系统.md)）、静默的动效、可访问性是硬约束。

## 布局骨架恒定项

- 自绘标题栏 36px（drag 区）；三栏：左栏 / 竖条 52px / 右栏 320px；主消息流 `max-width: 920px` 居中。
- ⚠️ 左栏宽度：01-UI 策划案实测 **280px**，MEMORY.md 最新硬约定为 **256px（走 `--left-w` 变量，栏宽与 `.hidden` 负边距共用同一事实来源，调整只改 `:root` 一处）**——以变量化后的代码现状为准。
- 阅读模式：左栏完全滑出、右栏 320px→30%、文档:消息 = 70:30；退出时**先恢复左栏再重渲染**（防闪烁）。
- 消息与输入框左缘对齐：`#chatScroll` 与 `#inputArea` 同为 920px 居中 + 左右 28px padding，AI 消息去头像后左边界**天然严格对齐**输入框（实测 delta=0，非新增偏移）。

## 动效规范

- **缓动**：进出场统一 `cubic-bezier(0.22,1,0.36,1)`；颜色过渡 ease；布局尺寸变化 ease-in-out。**时长 150–300ms**，布局大动效 0.28s。
- **双向协调动画**（成对设计，进/出互为逆过程）：
  - 左栏收起/展开：280→52px 0.28s ease-in-out 平推，内容不 display:none 而是 overflow:clip 逐渐裁剪滑出（真实平推感）；展开反向推回且**无入场动画**（避免拖沓）。
  - 阅读模式进出：`contentFloatIn`（放大上浮）/ `contentFloatBack`（缩放下沉）配对，0.28s。
  - 设置页进出：进场 200ms 标准缓动，返回即精确还原底层视图。
- **下拉渐显**：菜单默认隐藏用 `opacity + pointer-events`（不用 display:none，保证过渡）；设置页原生 select 已重写为自定义 `prefSelect`——0.18s `opacity 0→1 + translateY(4px→0)` 淡入、双 rAF 保证初始态布局完成后再加 .visible（否则淡入不生效）、chevron 同曲线旋转。所有下拉必须走门户方案挂 body + fixed（`.input-box` 的 overflow 会裁剪绝对定位弹层，历史故障"菜单透明不可点/被裁剪"的根因）。
- **reduced-motion 降级（硬约束）**：`prefers-reduced-motion` 全量动画降级已实现（`01/主页面.html:468-471`）；prefSelect、设置页进出等在 reduce 下直接显隐。
- **三条红线**：① 内容更新绝不触发容器动画（侧栏 transition 仅挂 `.anim` 类；列表签名守卫零重建）；② hover 不引起布局位移（唯二例外：`.btn:hover translateY(-1px)`、`.menu-item:hover` 刻意缩进）；③ 流式输出 33ms 节流。
- 性能血泪教训：base64 头像逐行赋值 540ms→Blob URL 共享 50ms；右栏无守卫重建 280ms→签名守卫常驻 0ms。**任何列表渲染必须带签名守卫**。
