# 去AI味设计

墨台的长期视觉纲领，代码注释原文：**「去 AI 味：中性色 + 墨色主按钮 + 克制蓝链接」**（`01/主页面.html:19`，已实现）。目的：避免"AI 产品感"与长时间科研使用下的视觉疲劳，与品牌"墨"字自洽。

## 四条纲领

1. **中性色打底**：大面积中性灰白（`--bg #F6F7F9`），无彩色背景铺底；彩色是稀缺资源，仅用于链接、状态、图表。
2. **墨色主按钮**：主按钮不用品牌色，用近黑墨色（`--primary-bg #0F172A`）作视觉锚点。
3. **克制蓝链接**：链接是界面唯一常规彩色元素（`--link #2563EB`），仅用于可点击文本，不做装饰。
4. **零 emoji**：主页面 emoji 数量为 0；状态与操作一律**内联 SVG**（viewBox 0 0 24 24、fill:none、stroke:currentColor、stroke-width:2、round，尺寸 9–40px，白名单 `SVG_ICON_RE`）。仅少量 Unicode 符号（`↑↓× →`）用于迷你控件。

## 字体与排版

- 界面字体 Instrument Sans，中文回退 PingFang SC / HarmonyOS Sans SC / Microsoft YaHei；中文正文行高 ≥1.75。
- 品牌物料中文用宋体（水墨学术气质）；设置页提供字体风格五档（黑体/楷体/宋体/行书/等宽）。

## 动效红线（已实现，必须遵守）

- 过渡统一 `cubic-bezier(0.22,1,0.36,1)` 150–300ms；
- **内容更新绝不触发容器动画**（签名守卫跳过重建、原位切换类）；
- hover 不引起布局位移（仅 background/color/box-shadow/transform）；
- `prefers-reduced-motion` 全量降级。

## 布局基线

左栏 256px（走 `--left-w` 变量，单一事实来源）/ 竖条 52px / 右栏 320px；主题切换是"换肤"不改版（布局、间距、组件位置、图标形态零变化）。

## 对商业化页面的延伸约束

[计费体系](../entities/计费体系.md) 的会员/充值页**禁止彩色渐变、大色块、营销风配色**（06 策划案硬约束），必须复用墨色设计令牌——这是去 AI 味纲领在商业化场景的直接应用。

## 状态

本纲领全部【已实现】并长期有效（MEMORY 硬约束），是产品页与后续所有界面的强制基线。
