# 宣传合规红线

墨台宣传物料必须遵守的合规约束，源于「策划案说了但代码没做」的能力落差风险：产品存在大量规划态能力，误宣会导致用户预期落空与口碑反噬。

## 七条红线（05 策划案 §7.1）

1. **科研辅助工具定位**：不承诺自动产出论文、不保证实验结论、避免「替代科研人员」。
2. **额度表述精确**：区分 Chat 基础模型会员无限 / Chat 高阶模型耗 Token / Work 运行耗积分，避免「全部无限」误解。
3. **数据安全如实说明**：本地优先、敏感操作需授权；不得宣称「绝对隔离」。
4. **效果标注真实**：标注真实任务与耗时，不使用无法复现的对比。
5. **待实现能力不宣传**：见下方禁用清单。
6. **密钥与隐私**：物料不得出现 API Key、PAT、真实用户数据；截图前脱敏。
7. **学术诚信**：不暗示代写论文、规避查重；明确「辅助」与「需研究者把关」边界。

## 禁用表述清单

| 禁止 | 原因 | 建议表述 |
|---|---|---|
| 「自动写论文 / 一键出论文」 | Agent 单次运行至 maxTurns 结束，无迭代循环 | 「辅助论文撰写与审校」 |
| 「完全隔离的沙箱」 | canUseTool 拦截可被绕过 | 「沙箱内执行代码，静态拦截 + 独立进程隔离」 |
| 「保证结论正确」 | 无评审智能体校验 | 「全流程轨迹可追溯，结果可复现」 |
| 「断网运行绝对安全」 | 断网为声明式 | 「可声明断网运行」 |
| 「全部额度无限」 | 三类额度口径不同 | 精确区分（见 [计费体系](../entities/计费体系.md)） |
| 「替代科研人员」 | 定位错误 | 「把重复劳动交给 AI，把思考留给研究者」 |
| 「智能体自主调度七类子智能体」 | 七类子智能体待实现 | 「内置科研技能与工具，覆盖文献到论文全流程」 |

## 明文禁止宣传的未上线能力

团队版、审辨迭代循环、七类子智能体、计费体系（积分/订阅/充值，上线前）、PPT 生成。核心纪律：**宣传口径与《Agent 系统设计》第九章能力边界表严格一致**。

## 边界如实声明（主动说明反而是专业背书）

- 沙箱定位「防误操作」而非绝对隔离；
- 断网为声明式、不可强制；
- 知识库为 BM25 词法检索（非向量语义检索）；
- 本地版签到防刷能力有限（诚实声明）。

## 执行机制

- **E1 物料能力核对清单**：每条功能宣称 → 对应验证记录，无记录不得出现；建议作为发布流程强制门禁。
- 竞品纪律：只做能力维度对比、不做量化对比、不贬损、不宣称「超越通用大模型」（本产品属工作流层）。
- 绝对化表述（领先/独家/最强）需有依据，否则删除。
