# 主题系统

墨台的换肤体系：基础 light/dark 双主题 + **十二套扩展主题**，全部通过 `html[data-theme]` 下的 CSS 自定义属性令牌块实现，无主题引擎依赖。核心纪律：**主题切换是换肤而非改版**——只改颜色与材质，几何量（布局/间距/圆角/字号/图标）像素级恒定。

## 是什么

- **主题清单**：light、dark（基础）+ modern-minimal（现代简约）、ink-green（只此青绿）、sky-sea（天空与海）、cinnabar（水墨江南）、nostalgia（城南旧事）、glass（万山红遍）、snow-moon（风花雪月）、peach-grove（桃林）、yanyun（燕云十六声）、white-snake（白蛇缘起）、office-daily（办公日常）、qq-classic（经典QQ）。主题 id 是稳定标识（CSS 选择器 + localStorage `cs-theme`），显示名可随设计变更。
- **66 项令牌契约**：每套主题**恰好 66 项令牌，十二套名字集合与顺序完全一致**（实测校验）。⚠️ 01-UI 策划案（编制于扩展落地前）记载"仅双主题已实现、六套待实现、30+ 令牌"——以本页面/MEMORY.md 实测为准。
- **侧通道令牌**：`--btn-primary-bg` / `--btn-primary-hover` / `--switch-on` / `--btn-primary-text` **不进 66 项主契约**，属"逐主题单变量覆盖"侧通道。主按钮文字色兜底 `#FFFFFF`：只有亮品牌色主题（如 qq-classic 亮蓝 + 深墨字 8.12:1）才定义 `--btn-primary-text`，未定义的主题行为不变。新增亮色主题优先走此通道，**不要为对比度压深品牌色**（会失真）。

## 新增主题的 4 类注册点（漏一个就出问题）

1. 令牌块（66 项完整赋值）；
2. 内容画布钉白规则的 `.chat-body` / `#rightPanel` 选择器列表；
3. 逐主题 `--btn-primary-bg` 覆盖块；
4. `webapp.ts` 主题卡数组 + 中英词条。

流程见技能 `theme-variant-extension`。选择器 = 设置页「外观」`.appearance-grid` 3 列网格（⚠️ 旧的 `#themeExtraSeg` 分段控件已不存在，01-UI/07 策划案中的相应描述过期）；`applyTheme()` 无白名单，加令牌块与卡片即生效。

## 质量门槛（为什么 + 踩坑）

- **ΔE 区分度门槛**：跨主题主色两两 **Lab ΔE76 ≥ 12**（同批新增 ≥ 15）；勿用 RGB 距离（暗色失真）。外壳相近可接受，区分度由主色+链接承担。
- **对比度硬约束**：正文 ≥ 4.5:1；主按钮文字/底色按"家族区间" 6.1–18:1 判定，离群即压深主色。
- **随壁纸二次调整**：壁纸就位后配色须跟随壁纸主色调再校一次（snow-moon/office-daily/yanyun 实测案例）；IP/品牌主题取色法 = 官方物料量化取色（平均饱和度+色相分桶），不凭印象。
- **「X 为主、Y 为辅」是结构性指令**：面积最大的层（外壳/画布/表面）承载"主"色，辅色只落小面积元素。
- **整族同位移**：用户说"某浅色再深/浅一点"时，须对渲染在 `--panel-bg` 之上的外壳镀铬族施加同一 Δ 位移，只改单令牌会吃掉叠层控件；三条校验容差不可统一套用。
- **玻璃红线**：`--surface-2` 实色、blur 只挂 .panel/.modal；正文与节点文字必须实色。
- **暗色阴影规律**：暗底不透明度显著提高（0.03→0.20、0.16→0.50）。
- **钉白分层**：标题栏 #mainHeader 无条件钉回亮色基；设置页外壳随主题、`.settings-paper` 内容区全主题钉白（见 [设置页](设置页.md)）。
