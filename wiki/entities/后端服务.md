# 后端服务（app/src/server/）

墨台的本地 Node/Express 后端，由 Electron 主进程 fork（内置 Node 20），仅绑定 `127.0.0.1`，全部 `/api/*` 走随机 Bearer token 鉴权，承载约 40 个端点与 Work 模式全部执行调度。前端不承载任何智能体推理逻辑。

## 模块地图（按实际源码）

| 文件 | 职责 |
|---|---|
| `index.ts` | 启动装配：CORS → token 鉴权中间件 → Work 路由 → 既有 API；`/api/health`、`/api/state` 读写（原子写）、`/api/fs/list`（深度 3、上限 400、跳过 node_modules/.git 等）、`/api/fs/raw`（≤64MB）；`tryListen` 端口候选回退；内建智能体按 id 增量播种（不覆盖用户编辑，废弃 builtin 自动移除）；启动即跑沙箱 GC |
| `routes.ts` | 全部 `/api/work/*` 路由：bootstrap 注水、沙箱 12 端点、agent/run、qoder config/ping、技能 5、MCP、agents、kb 3、run-history、notes 4、记忆/hooks/worktrees（读 `userdata.ts`）等；挂在鉴权中间件之后 |
| `store.ts` | `work.json` 分区串行化持久化（promise chain 防多窗口读-改-写交错）；分区：agents / subagents / skills / mcpServers / sandboxPolicy / modelToolSupport / runHistory / seeded / domainPlugins / prefs；原子写 tmp+rename；与前端 `state.json` 互不覆盖 |
| `qoder.ts` | Qoder Agent SDK 封装（Work 底座）：`runWorkTurn`、`makeCanUseTool`、`buildScienceServer`（in-process 科研工具）、技能插件管理、`ping`、`byokModelsReady`；`loadSdk()` 惰性动态加载（见踩坑）；`settingSources:[] + strictMcpConfig:true` 是隔离关键，否则继承本机全部用户配置 |
| `sandbox.ts` | 沙箱执行引擎：execCode / installDeps / 文件 API / GC / 声明式断网钩子注入；scope 目录 `data/sandbox/<scope>/{work,out,.hooks,.meta.json}`；输出环形采集 head 60%+tail 40%；⚠️ `detectRuntimes` 包装忽略 force 参数（已知缺陷） |
| `proc.ts` | 子进程与运行时管理：`detectRuntimes()`（python/node/uv/npm，TTL 6h 落盘缓存 runtimes.json）、`resolveExecutable()`（Windows 裸名经 where.exe 解析，npm/uv 是 .cmd 包装）、`killTree()`（必须 `taskkill /T /F` 杀进程树）、`spawnGuarded()`（shell:false + argv 数组 + stdin 关闭 + 隐藏窗口） |
| `policy.ts` | 沙箱策略与路径守卫：`DEFAULT_POLICY`（120s 超时 / 256KB 输出 / 并发 2 / 单文件 20MB / network:'declared' / autoGcDays:7）；`assertInside` + `sanitizeRelPath` 防 junction/symlink 逃逸；`DANGER_PATTERNS` 16 类危险命令静态拦截（防误操作不防绕过） |
| `kb.ts` | BM25 词法检索：K1=1.5/B=0.75，中文 bigram + 英文按词，600/80 分块，MAX_TEXT 900k；前端推送已解析文本，后端不解析二进制；诚实定位非语义 |
| `notes.ts` | 实验笔记存储 `data/notes/*.json`；Agent 的 note_write 与前端笔记本页共用同一份（核心设计） |
| `ai.ts` | 多厂商流式代理：OpenAI 兼容协议，8 厂商 URL（deepseek/zhipu/bailian/tokenplan/ark/openrouter/opencodezen/opencodego），短别名归一化失败显式报错；`pumpSse`/`chatStream`/`applyThinking`/`applyWebSearch`；Key 仅存 `server/config.json` |
| `research.ts` | 科研检索工具：arXiv / fetchUrl / web_search，全局 fetch 零依赖；web_search 依赖第三方 HTML 结构（脆弱，失败返回明确错误） |
| `sci-tools.ts` | 六个纯本地计算工具：doi_cite / latex_check / unit_convert / name_normalize / figure_caption / keyword_expand；函数与 MCP 薄包装分离，可单测 |
| `domain-tools.ts` | 领域插件 in-process MCP 工具（research-math 精确分数等）；因插件 stdio server 实测不可靠启动，改宿主同通道注册 |
| `userdata.ts` | 用户级 Qoder 数据访问（设置页真实数据源）：读 `~/.qoder-cn` 的 memory/projects/settings；realpath 前缀校验防穿越、删除走软删除（移临时目录）、git worktree 只读 |
| `audit.ts` | 工具调用审计 JSONL（`data/work-audit.jsonl`）：PreToolUse→PostToolUse 落时间/工具/参数摘要/结果/耗时/发起方；禁止含凭据；写入失败不阻断会话（旁路非闸门） |
| `sse.ts` | SSE 助手：统一帧格式 `data: {"evt":...}`、心跳保帧、客户端断开回调 |
| `skills-plugin/` | 技能插件构建工具（经 tsconfig.verify.json 编译） |

## 踩坑记录

- **ERR_REQUIRE_ESM（打包版致命）**：SDK 纯 ESM × Electron 内置 Node 20 无 require(esm) → server 模块加载静默失败、所有 `/api/*` 无人监听；且 tsc 会把动态 `import()` 改写回 `require()`——解法为 Function 间接层（`shared/qoder-sdk.ts` 的 `loadSdk()`）。详见 [构建打包体系](../entities/构建打包体系.md)。
- ⚠️ 端点计数口径：迁移说明记 routes.ts 29 端点，backend 策划案记核心 6 + Work 33 ≈ 40，实际源码路由更多（bootstrap/plugins/记忆等新增），以源码为准。
- 已知缺陷三处（思考开关 / force 参数 / 错误文案括号）详见 [ts-migration 第七节](../sources/ts-migration.md)。
