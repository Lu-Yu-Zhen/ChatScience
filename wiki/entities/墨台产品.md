# 墨台产品

墨台是桌面端科研 AI 工作台（Chat 轻对话 + Work 墨道多智能体双模式），视觉基调为水墨美学 × 现代效率工具。

## 命名关系

| 层级 | 名称 | 说明 |
|---|---|---|
| 主品牌/产品名 | **墨台**（MoTai） | 唯一对外产品名 |
| 核心智能体系统 | **墨道**（Modao） | Work 模式的多智能体系统 |
| 英文名/工程代号 | **ChatScience** | 代码、包名、目录沿用；对外表述「墨台 ChatScience」 |
| 轻量模式 | Chat | 无独立命名 |
| InkForge / 墨砺 | 仅作视觉基因库 | 命名已放弃，与「墨台」冲突 |

⚠️ 历史遗留：项目曾四套名称并存（墨台/ChatScience 粉蓝气泡图标/墨砺 InkForge/海报 CHATSCIENCE），MEMORY.md「品牌与设计」已裁定统一，但**应用图标重绘等整改项仍属待实现**。英文站命名：MoTai / Modao。

## VI 四色与辅助图形

| 角色 | 色值 | 应用 |
|---|---|---|
| 玄黑 | `#16161D` | 品牌重色、印刷品 |
| 石青 | `#2E6E8E` | 品牌强调、图表主色 |
| 丹朱 | `#CE4928` | 印章感点缀，极少量 |
| 宣白 | `#F4F0E5`（MEMORY 定值） | 物料底色 |

⚠️ 宣白色值两处不一致：05 策划案写「`#F6F7F9` / 米白 `#F7F5EE`」，MEMORY 定值 `#F4F0E5`——以 MEMORY（最新裁定）为准。

- 界面令牌另成体系：`--primary-bg #0F172A`、`--link #2563EB`、`--bg #F6F7F9`（UI 用，不与品牌色卡混用）。
- 辅助图形 4 个：同心墨痕、分子网络、粒子散点、方形朱印。
- 主张语：**「轻对话用 Chat，深科研交给墨道」**（主传播语）；品性语「格物砺知」；理念层「让科研从重复劳动中解放，把精力还给思考」。
