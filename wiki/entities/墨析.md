# 墨析（对话只读智能体）

内置智能体 `agent-discuss`，定位「讨论」：读用户的代码与文档，讨论思路、答疑、审阅方案，**不改动任何文件**。与 [墨道](墨道.md) 构成当前 `BUILTIN_AGENTS` 的两位成员——一个编排执行、一个只读探讨。

## 配置（源码实测）

| 项 | 值 |
|---|---|
| role / builtin | research / true |
| systemPrompt 要点 | 科研探讨伙伴；只读取与分析，绝不修改文件；回答先给结论再给依据；引用用户文件注明文件名与大致位置 |
| tools.sdk | Read / Glob / Grep / WebFetch / WebSearch（无 Write/Edit/Bash/Agent） |
| tools.scienceTools | arxiv_search, fetch_url, web_search, kb_search |
| skills | paper-deep-read, formula-derivation, model-arch-analysis, lit-review |
| modelKey / permissionMode / maxTurns | byok / default / 16 |
| sandbox | scope: global |

只读性由**双重保障**实现：工具白名单不含任何写类工具 + `permissionMode: default`。不挂 `Agent` 工具，故不参与委派、也不能委派子智能体。

## 命名与品牌

- 主张语「轻对话用 Chat，深科研交给墨道」——墨析是 Work 体系内的轻量只读入口，与 Chat 模式（厂商模型链路）区分。⚠️ 04 策划案编制时此智能体仅记为「讨论（第 5 个 id），已注册」且界面切换器不显示；现已升格为具名内建智能体「墨析」，策划案相应描述过时。
