# 计费体系

墨台的商业化计量与订阅设计：双账户（积分/Token）× 会员档位（个人四档 + 团队三档），以功能门禁实现算力与权限解耦。

## ⚠️ 状态：设计蓝图，尚未上线

**全代码库检索证实实质性零实现**——无计费端点、无积分/会员/签到/充值/门禁/看板；`chatStream()` 完全不读上游 `usage`（最大技术缺口）。唯一残留是 `01/webapp.js:182,276` 的 i18n 键 `upgrade:'升级 Pro'`（无调用点）。本页所述均为【策划确认/待实现】的设计蓝图，引用时须区分规划态与已落地实现；上线前受 [宣传合规红线](../concepts/宣传合规红线.md) 约束不得宣传。

## 核心不变式（MEMORY「计费体系不变式」）

1. **算力与权限彻底解耦**：余额决定能不能跑，档位决定能用哪些高级功能。**禁止**「买积分送功能」「买会员送算力」。
2. **到期规则**：权益收回 + 余额保留（积分/Token 与会员订阅是两条独立生命周期，数据结构必须分离存储）。
3. **充值包只补算力不带权益**（积分包 / Token 包两类）。
4. **签到 100 积分/日**，与套餐积分合并、同有效期（当月有效、月底清零不结转）。
5. **免费用户注册赠 200 初始积分**，余额 > 0 即可运行 Work 基础能力（获客设计核心）。
6. **阶梯计价透明**：基础工作流 1 积分起，按复杂度因子（智能体数、工具调用数、迭代轮次、沙箱时长、仿真、批量）上浮；任务前预估、任务后实际消耗与依据。
7. **付费路径**：兑换码（冷启动）→ 在线支付。

## 档位概览（规划值）

- 个人四档：49 / 139 / 299 / 699 元/月（高阶 Token 200 万—3000 万、积分 2000—30000、功能权益递增）；四档均享 Chat 基础模型无限。
- 团队三档：89 / 199 / 369 元/月，对标个人档、额度略高、团队共用。**前置为账号体系 + 云服务（架构级缺失，纯本地单机应用）**。
- 权益分批上线：批次一用已实现能力（12 技能、6 工具、5 档模型、自定义 API）撑起四档差异；迭代/模板/快照/仿真等待能力落地后开启。

## 技术落地要点（规划）

- store 新增 6 分区：account / credits / tokenAccount / usageDaily / checkin / pricing；流水 append-only + 启动对账。
- 门禁统一入口 `checkEntitlement` + 服务端强制（前端仅展示）；任务开始校验余额、结束按已完成步骤结算。
- 本地单机计费诚实定位为「自律性计量」，真实商业化必须引入云端账号与账本。
- 法务合规（预付费/虚拟额度/退款/发票）为 P0 前置决策。
- 前端界面须遵循 [去AI味设计](../concepts/去AI味设计.md)：会员/充值页禁彩色渐变与大色块。
