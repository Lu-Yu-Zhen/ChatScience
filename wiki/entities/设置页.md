# 设置页

墨台的独立全屏设置界面：由左下角齿轮打开的**全屏覆盖层 `#settingsPage`**（body 直挂、fixed inset:0、`top: var(--titlebar-h,36px)` 让位自绘标题栏），左侧导航 + 右侧内容，六组十五项，取代旧弹出下拉框。

## 是什么

- **导航六组十五项**（落地版，MEMORY.md 2026-09-16）：
  1. 通用：个人设置（头像/昵称/邮箱/语言 + 本地真实统计）、主题（外观网格选择器 + 字体风格五档 + 字号滑条）
  2. 模型：模型配置（自 modal 迁入）
  3. 墨道·Work：智能体 / 沙箱 / 笔记本 / 运行 / 记忆
  4. 知识与扩展：知识和数据库 / 技能与插件 / 连接器
  5. 智能体行为：钩子 / 电脑操控
  6. 工作区：Git / Worktrees
  - ⚠️ 07 策划案 §3 定稿表把「记忆」列在智能体行为组，MEMORY.md 落地版归入墨道·Work 组——以代码现状复核为准，此处如实标注出入。
- **入口迁移**：智能体/沙箱/笔记本/运行四项**唯一挂载点=设置页**（自 Work 侧栏删除，侧栏 9 项→5 项，rail 收起态自动跟随）；知识与数据库/技能与插件/连接器**双入口保留**——侧栏与设置页共用同一构建函数 + 同一份数据，一处改动两处可见。
- **兼容路由**：`openWorkPage` 收到 work-agents/sandbox/notebook/run 一律转发 `openSettings(section)`；深链（欢迎页 pills、"请先在设置中添加模型" toast）全部落到正确 section。

## 交互设计（为什么）

- **覆盖层而非 view 分支**：底层三栏 DOM 原样保留 → 返回（左上「← 返回」或 Esc）即精确还原，进行中的 SSE 流式回复不中断，回归面最小。
- **落点优先级**：深链 > 上次访问（localStorage `cs-settings-section`）> 个人设置。
- **幂等守卫**：点击已选中的同一导航项不刷新（`showSettingsSection(id, force)`）；设置页内刷新**不得直接调 renderMessages()**（在覆盖层后面=点了没反应），统一走 `Work.rerender()` 或 `refreshPapersDb()`，且 **rerender 必须传 force**。
- **配色分层**：外壳（顶栏+导航）随主题（`--settings-shell`），内容区 `.settings-paper` 全主题钉白后改淡灰 `--settings-canvas: #F8F9FB`，卡片保持纯白——与聊天画布钉白是同一裁定（见 [主题系统](主题系统.md)）。

## 真实数据对接（userdata.ts）

设置页的钩子/记忆/Worktrees 等面板不是摆设，后端由 `app/src/server/userdata.ts`（用户级 Qoder 数据访问层）供真实数据，路由注册于 `routes.ts`：

- `GET /api/work/qoder/memories` — 真实扫描 `~/.qoder-cn` 全局+项目记忆清单（不虚报）；
- `DELETE` 记忆走**软删除**（移动到系统临时目录，不直接 rm）；
- `GET /api/work/qoder/hooks` — 只读反映用户级 settings.json 中声明的 Hooks；
- `GET /api/work/worktrees` — git worktree 列表**只读**（`list --porcelain`），不改仓库；
- prefs 归一化 `normalizePrefs` 落 `work.json` 的 prefs 区。
- 安全边界：所有读写限制在 qoderHome 内（realpath 前缀校验防穿越）。
- 能力状态如实标注：未落地能力标「本地配置 · 后端联动筹备中」，不虚标可用性。
- 偏好持久化：各面板一份 JSON 于 localStorage（`cs-set-hooks / cs-set-memory / cs-set-computer / cs-set-git / cs-set-worktrees`），变更即时写入。
