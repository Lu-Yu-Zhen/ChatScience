## 关键决策（与源码仍一致的部分）

- **不自研 Agent 循环**，一切交给 Qoder Agent SDK，自研只做科研领域价值 `墨台实现策划案/_src/04-Agent系统设计.md:78`。
- **隔离三件套缺一不可**：`settingSources: []` + `strictMcpConfig` + `tools` 白名单；实测缺任一项 SDK 会继承本机配置并泄漏数百个 MCP 工具 `墨台实现策划案/_src/04-Agent系统设计.md:79`，六重隔离清单见 `:369-377`。
- **cwd 指向沙箱工作目录**、**多轮走 SDK 原生 resume 不手工拼历史** `墨台实现策划案/_src/04-Agent系统设计.md:80-81`。
- 主智能体三职责（意图路由 / 汇总判定 / 异常重规划）与**三分支路由**，纪律是「绝不机械地为每个任务都拉起全部子智能体」`墨台实现策划案/_src/04-Agent系统设计.md:480-493`。
- 子智能体之间不得互相调度，调度权唯一归属主智能体 `墨台实现策划案/_src/04-Agent系统设计.md:493`。
- **唯一权限网关 + 六步信息流转**（裁剪下发→执行→回传→冻结）`墨台实现策划案/_src/04-Agent系统设计.md:390-391`。
- 审辨迭代循环：评审打分不达标则回环重做，迭代上限受档位控制 `墨台实现策划案/_src/04-Agent系统设计.md:499-505`。
- 决策点 **N2**：SSE 桥接层必须透传 `parent_tool_use_id`，否则嵌套时间线（E7）无法实施 `墨台实现策划案/_src/04-Agent系统设计.md:2882`；**N1**：文件检查点与外部会话存储在 SDK 层二选一 `:2881`。
- 自我约束：「落地并验证前一律不得对外宣称已实现」`墨台实现策划案/_src/04-Agent系统设计.md:621`，能力边界要如实声明 `:522-538`。
