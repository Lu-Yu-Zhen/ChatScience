# 05-宣传板块实现策划案

> 一句话摘要：这份策划案盘点了墨台宣传资产的现状与四套品牌名并存的风险，给出"墨台/墨道 为唯一产品名"的统一方案，并把七条宣传合规红线定成硬纪律。

## 这份资料讲了什么

八节结构：一 板块定位与现状（资产盘点、关键风险）→ 二 品牌体系统一方案【待实现】→ 三 品牌主张与 Slogan → 四 目标人群与核心卖点 → 五 渠道矩阵与内容选题【待实现】→ 六 上线节奏与转化路径【待实现】→ 七 宣传合规与风险规避 → 八 物料产出清单【待实现】（`墨台实现策划案/_src/05-宣传.md:3`、`:92`、`:154`、`:202`、`:249`、`:312`、`:369`、`:403`）。带【已实现】/【待实现】标记，是判断"能不能拿去宣传"的原始依据。

## 最高优先级问题：四套品牌名并存

`墨台实现策划案/_src/05-宣传.md:68-77` 列出四个互不一致的标识：产品策划案用 墨台 / 墨道（东方水墨，文本规划阶段）；已接入应用的图标是 ChatScience 粉蓝气泡（粉色渐变 SaaS 风）；InkForge 提案用 墨砺 / InkForge（玄黑+石青+丹朱，未接入）；既有海报用 CHATSCIENCE（宝蓝科学风）。案文判定"在品牌名与视觉未统一前，任何投放都会造成认知混乱与资产浪费"。

裁定建议（`墨台实现策划案/_src/05-宣传.md:79-90`）：品牌名以「墨台 / 墨道」为唯一产品名；英文名保留 ChatScience 作为工程代号（代码、包名、目录、技能命名已全面使用）；InkForge 只作视觉基因库（色卡/辅助图形）采纳、放弃其命名；应用图标重做。

## 合规红线（§七.1）

七条，逐条对应可执行动作（`墨台实现策划案/_src/05-宣传.md:371-381`）：

1. 科研辅助工具定位——不承诺自动产出论文、不保证实验结论、避免"替代科研人员"；
2. 额度表述精确——区分 Chat 基础模型会员无限 / Chat 高阶模型耗 Token / Work 运行耗积分，避免"全部无限"误解；
3. 数据安全如实说明——本地优先、敏感操作需授权，**不得宣称"绝对隔离"**（沙箱拦截可被绕过是已声明边界）；
4. 效果标注真实——标注真实任务与耗时，不使用无法复现的对比；
5. 待实现能力不宣传——团队版、审辨迭代循环、七类子智能体、自动生成 PPT、计费体系；
6. 密钥与隐私——物料不得出现 API Key、PAT、真实用户文献/数据，截图需清理；
7. 学术诚信——不得暗示代写论文、规避查重，需写明"辅助"与"研究者把关"的边界。

另有两条口径纪律：宣传口径必须与《Agent 系统设计》板块第九章的能力边界表严格一致（`墨台实现策划案/_src/05-宣传.md:198`）；团队侧能力完全为零实现，团队版卖点与 Slogan 不得在任何投放中启用（`墨台实现策划案/_src/05-宣传.md:213`）。§五.3 再把"不宣称待实现能力"列为内容纪律（`墨台实现策划案/_src/05-宣传.md:299-304`）。

## 与现状的关系

红线第 5 条点名的能力，如今实现状态不一：计费体系确实零实现（见 [06-订阅预付费板块实现策划案](plan-06-billing.md) 与 [账本与计费](../entities/ledger-billing.md)），团队侧仍是缺口，而子智能体已经落地。⚠️ 冲突：本案把"七类子智能体"列为上线前不得宣传的待实现能力（`墨台实现策划案/_src/05-宣传.md:379`），运行时却已注册七类科研子智能体（`app/src/server/qoder.ts:182`），详见[子智能体体系](../entities/subagent-system.md)。品牌命名的落地现状见[品牌与命名纪律](../concepts/brand-naming.md)，红线的可执行清单见[宣传合规红线](../concepts/promo-compliance.md)。
