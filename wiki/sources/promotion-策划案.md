# 05-宣传板块实现策划案（摘要）

墨台品牌体系与宣传推广的完整策划：盘点既有品牌资产、裁定四套名称并存的统一方案、规划 Slogan 体系、渠道矩阵、上线节奏与合规红线。

## 关键结论

1. **最高优先级风险：四套品牌名并存** —— 策划案「墨台/墨道」、已接入图标「ChatScience 粉蓝气泡」、InkForge 提案「墨砺」、海报「CHATSCIENCE」。裁定建议：以「墨台/墨道」为唯一产品名，ChatScience 保留为英文名/工程代号，InkForge 降为视觉基因库（采纳四色与辅助图形，放弃命名），应用图标重绘。详见 [墨台产品](../entities/墨台产品.md)。
2. **既有资产**：InkForge 品牌提案 11 张（6 概念稿 + 定稿 Logo + VI 手册 + 3 场景图）、科研 Agent 宣传海报 1 张（文案完整可复用）、粉蓝气泡图标 3 件（与品牌脱节，P0 重做）。
3. **Slogan 体系**：主传播语推荐「轻对话用 Chat，深科研交给墨道」（命中双模式分离这一唯一性架构差异，且已实现）；另有理念层/传播层/品性层三套表述。
4. **卖点状态核对**：五点差异化卖点中——双引擎分离、可插拔 MCP 生态已实现可用；工作台编排、独立选模型需调整表述；算力/功能解耦依赖 [计费体系](../entities/计费体系.md)（零实现）不得宣传。
5. **渠道矩阵**：B 站/小红书 P0，知乎 P1，学术公众号/学术社区 P2（需团队版）。选题库给出 16+ 个基于真实验证证据的选题。
6. **上线节奏**：预热/内测个人版可立即执行（不必等计费）；公测依赖积分签到、正式依赖付费体系、团队依赖账号体系（架构级缺失）。
7. **转化路径洞察**：Chat 即时价值是零门槛获客入口，Work 跑通第一个工作流（arXiv 检索精读黄金路径）是转化拐点。

## 合规部分

- 七条合规红线 + 禁用表述清单 + 内容纪律（证据可复现、真实截图优先、Key 脱敏）→ 详见 [宣传合规红线](../concepts/宣传合规红线.md)。
- E 组物料核对纪律：「物料中每一条功能宣称 → 对应验证记录」，无验证记录不得出现。

## 状态

- 【已实现】资产盘点与实测结论（海报、图标、InkForge 提案、能力边界核对）。
- 【待实现】品牌统一决策（P0 阻塞项）、Logo/图标重绘、物料产出、渠道启动、落地页。
