# UI 板块实现策划案摘要

墨台桌面客户端全部视觉与交互设计层的实测策划案：以"已实现内容为唯一事实基准"裁定与总策划案的冲突，系统梳理设计令牌、主题、字体、栅格、组件、图标、动效与可访问性。

## 核心内容

- **编制原则**：凡与《产品整体策划案》冲突一律以已实现为准（如左栏 280px 而非 240px、4px 半栅格而非纯 8px、Instrument Sans 字体、10 档字号）。全文用【已实现】/【部分实现】/【待实现】三态标记。
- **设计语言**："去 AI 味：中性色 + 墨色主按钮 + 克制蓝链接"，零 emoji，详见 [动效与布局约定](../concepts/动效与布局约定.md)。
- **设计令牌体系**：30+ 项 CSS 自定义属性成对定义于 `01/主页面.html:20-109`，`html[data-theme]` 切换；五组语义分组（基础/边界/文字/品牌交互/语义状态）是主题扩展的映射骨架；清点出 9 处硬编码颜色技术债（15.2 节 A 组归位清单）。
- **主题系统**：⚠️ 本案（2026-09 编制）记载"仅 light/dark 双主题已实现、六套扩展待实现"，但项目后续已实际落地十二套扩展主题——以 [主题系统](../entities/主题系统.md) 为准。
- **布局骨架**：自绘标题栏 36px + 三栏（左 280/52px、中 flex 自适应、右 320px）+ 阅读模式 70:30；⚠️ MEMORY.md 最新约定左栏已改走 `--left-w` 变量 256px，与本案 280px 记载不一致。
- **组件规范**：按钮 4 类、输入区、门户式下拉（含"菜单透明不可点/被裁剪"两大故障的根因与修复）、Modal、芯片、时间线 trace、Jupyter 笔记本、msgNav、文件选择、PDF 阅读器。
- **动效规范**：3 档缓动、6 档时长、8 个命名动画、三条动效红线与两条性能血泪教训（base64 头像 540→50ms、签名守卫 280→0ms），详见 [动效与布局约定](../concepts/动效与布局约定.md)。
- **落地清单**：第十五章 A–E 五组施工顺序（令牌归位→缺陷修复→主题扩展→中文排版→可访问性）。
- **品牌风险**：9.3 节指出四套品牌视觉并存（粉蓝气泡 logo / InkForge 提案 / ChatScience 海报 / 「墨台」命名），需产品决策统一。
