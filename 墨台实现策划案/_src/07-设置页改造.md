## 5 · 页面跳转与返回交互（定稿）

**载体：全屏覆盖层 `#settingsPage`**（body 直挂，fixed inset:0，z 高于三栏），而非新增 view 分支。理由：
- 「独立完整页面」语义最贴近（整窗替换，与参考截图一致）；
- 不动 renderMessages / renderConversations / setSidebarMode 任何分支，底层 DOM 原样保留 → 返回即精确还原，回归面最小；
- Work 构建器返回 `{node, title, desc, wide}`，可直接挂进设置内容区，title/desc 用在设置页自己的面板头。

**进入**：
- 点击齿轮 → `openSettings(section?)`；body 加 class 锁底层滚动；进场 200ms `cubic-bezier(0.22,1,0.36,1)`，`prefers-reduced-motion` 时直接显隐；
- 默认落点：直接点击齿轮 → 上次访问的 section（localStorage `cs-settings-section`，可选）；由深链触发 → 直接定位指定 section（如「请先在设置中添加模型」→ models）；
- 页内导航：点击左导航切换右面板，当前项石青高亮；面板挂载时走各自构建器（WorkState 懒加载逻辑不变）。

**返回**：
- 左上「← 返回」（复用词条 `back`）+ **Esc 快捷键**；
- 返回 → 移除覆盖层、解锁滚动，底层视图原样呈现（含进行中的流式回复，SSE 不中断）；
- 设置期间主题 / 语言 / 模型变更即时生效于底层（applyTheme / applyLang 为内容级更新，符合「内容更新不触发容器动画」纪律）。

**双入口一致性**：
- 技能与插件 / 连接器 / 知识与数据库：侧栏入口保持现行为（`openWorkPage('work-skills'|'work-mcp')` / `openPapersDb` 直开中心视图），设置页 section 与之**共用同一构建函数 + 同一份数据**（WorkState / 后端 store），一处改动两处可见，零复制代码。
